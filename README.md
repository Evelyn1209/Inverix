# Inverix

Sistema web de gestión de inversiones a plazo fijo, desarrollado como proyecto de programacion V en la carrera de Ingeniería en Computación (Universidad Castro Carazo).

## Tecnologías

- C# y ASP.NET
- SQL Server
- HTML y CSS
- Arquitectura Modelo-Controlador-Vista (M-C-V)

## Estructura del proyecto

- `Classes/`: clases del modelo
- `Controllers/`: lógica y controladores
- `Views/`: páginas de la interfaz
- `DataBase/`: acceso a datos [y script de la base de datos, si está aquí]
- `Styles/` e `Images/`: estilos e imágenes

## Cómo ejecutarlo

1. Clonar el repositorio.
2. Crear la base de datos en SQL Server [usando el script incluido, si existe].
3. En `Web.config`, cambiar la cadena de conexión `Conexion` por el servidor propio.
4. Abrir `Inverix.slnx` en Visual Studio y ejecutar.
